作品名

Mappin'

（マッピン）— 登山準備の早送りマップ

お題「▶︎▶︎」の解釈

▶︎▶︎ ＝ 連なる山々 ＋ 早送り（タイパ）

  • 登山の事前準備——クマ出没・登山道・山小屋・トイレ——は都県ごとにバラバラ
  • その面倒を1画面に早送り。準備不足による遭難と行政コストを減らす

作品URL — いま皆さんのスマホで開けます

https://fumi-june.github.io/ai-hackathon-2026/hikemap/

  • 公式の危険情報 59ピン（3都県横断）・ワンタップで公式ページ直行
  • 登山道24本 — 自分のルートをタップすると沿線500mの情報だけ浮かぶ
  • その場で誰でも投稿（写真つき）— 双方向の目撃網

▶ ライブデモ：ピン→公式直行 ／ 大倉尾根タップ→沿線集計 ／ 会場から投稿

開発に使用したツール類

  • Claude Code — 設計・実装・デプロイ・データ構築（公式発表＋OSMからピン59・ルート24本をAIが抽出・検証）
  • Leaflet ＋ 国土地理院地図 — 地図表示（GitHub Pages配信）
  • Cloudflare Workers ＋ KV — 投稿・写真の共有バックエンド
  • OpenStreetMap / Overpass API — 登山道・山小屋・トイレの線形と位置
  • Google Chat — URL・コメントを共有／Let's note から EVO-X2 を遠隔操作

※ 今回は海外と日本で連携して開発したため、機材構成は遠隔でのやり取りを想定したものになっている
